# DigitLab — SVM digit evaluation website

## Run on Windows

1. Extract the project ZIP to a normal folder (for example, Desktop\svm-digit-site).
2. Double-click `start-website.bat`.
3. The first run installs the Python packages. Wait for the site to open in your browser.
4. Keep the black server window open while using the site. Upload the `.tra` training file and `.tes` test file there.
5. Close the server window to stop the website.

Python 3.10 or newer and an internet connection for the first package installation are required. You can also start it from PowerShell opened in this folder by running `./start-website.bat`.
